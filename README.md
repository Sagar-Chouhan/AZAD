# AZAD

Repository containing Azad Foundation projects:
- **azad**: Azad Foundation MIS (FastAPI backend + responsive web application)
- **Azad-LMS**: Azad Learning Management System (LMS backend, React frontend, and mobile module)

## Setup & Running

Refer to the respective project directories:
- `azad/`: See `azad/start.bat` / `azad/start.ps1`
- `Azad-LMS/`: See `Azad-LMS/install.ps1`
